# PDF Studio

Bộ công cụ PDF chạy hoàn toàn trong trình duyệt, một file HTML duy nhất (`index.html`), không gửi dữ liệu lên mạng.

- **Ghép hồ sơ**: kéo thả trang, gộp theo lô theo số file / dung lượng, nhận cả file .zip, tự bỏ file trùng nội dung.
- **Chỉnh sửa**: cắt vùng nguyên điểm ảnh gốc, che, chèn chữ / chữ ký, khớp nét với bản mẫu (có hỗ trợ Gemini), bỏ lớp che, mở nhiều file, tự lưu phiên.
- **Nén**, **Làm nét bản scan**, **Cắt tách trang** theo trang / số file / dung lượng.
- Nhận PDF và ảnh PNG, JPG, TIFF (kể cả fax CCITT), BMP, GIF, WebP.

Mở trực tiếp `index.html` hoặc truy cập `/pdf/` trên trang web.
