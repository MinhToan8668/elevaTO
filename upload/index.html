Tải file lên Telegram

Video, tài liệu, ảnh, file nén… đều được. Bot gửi file vào chat Telegram của bạn; cần lại thì tải về thành một file ở mục Kho.

Bấm để chọn file (chọn được nhiều file), hoặc kéo thả vào đây Mọi loại file · tối đa 2GB mỗi file

    File đi thẳng từ máy bạn lên chat Telegram — không qua Google Drive. File trên 19MB được cắt thành nhiều phần (Telegram chỉ cho bot lấy lại phần ≤20MB); lấy về thành một file ở mục Kho bên dưới, không phải ghép tay. Lỡ đóng trang thì chọn lại đúng file, bấm Tải lên là gửi tiếp phần còn thiếu.

    Kho file trên Telegram

    File bot đã gửi vào Telegram, tải về được hai đường — đường nào cũng không cần vào Telegram và không phải ghép tay.
    Tải thẳng: file đi từ Telegram về máy luôn, không đặt bản nào trên Drive, bấm là tải ngay.
    Lấy về Drive: bot ghép file đặt tạm trên Drive (chờ 1–2 phút, bản tạm tự xoá sau 24 giờ). Chậm hơn nhưng không giới hạn dung lượng — file lớn thì dùng đường này.
