Gộp PDF hoá đơn

Chọn một lần vài trăm file PDF (hoặc file .zip khách gửi). Tool tự chia thành các bản gộp vừa giới hạn upload rồi gộp. Mọi thứ chạy trên máy bạn, không có file nào bị gửi lên mạng.

Kéo thả file PDF / ZIP / cả thư mục vào đây, hoặc nhấn để chọn Không giới hạn số file. File trùng nội dung sẽ tự bỏ.
Bản gộp quá nặng là lý do hay bị lỗi khi upload. Nếu vẫn lỗi, giảm dung lượng mỗi bản (vd 10 MB). Tool sẽ chia ra nhiều bản hơn.
